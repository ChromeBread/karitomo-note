Use it on stream (OBS) one page to touch, one page to show

1Touch: a custom dock

In OBS, open Docks → Custom Browser Docks
and add the app's address.
Tap, scroll and type in it as usual.

2Show: a browser source

Add a Browser source to your scene with
the same address plus ?obs at the end.
"Local file" off, a tall size (e.g. 540×960).

3Just use the dock

The shown page follows the page you open,
your scrolling and simulator searches.
No WebSocket setup needed.
